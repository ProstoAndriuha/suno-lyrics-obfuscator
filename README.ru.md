# Suno Lyrics Obfuscator

[English](./README.md) | **Русский**

[![Открыть приложение](https://img.shields.io/badge/открыть-приложение-7c3aed?logo=github)](https://prostoandriuha.github.io/suno-lyrics-obfuscator/)
[![Лицензия: MIT](https://img.shields.io/badge/лицензия-MIT-10b981.svg)](./LICENSE)

Небольшой браузерный инструмент для Unicode-преобразования текста с сохранением видимой структуры песен и других форматированных материалов.

**[Открыть приложение](https://prostoandriuha.github.io/suno-lyrics-obfuscator/)**

## Возможности

- Интерфейс на русском и английском языках.
- Режимы невидимых символов, мягкого переноса и кириллических омоглифов.
- Сохранение отдельных структурных тегов: `[Куплет]`, `[Припев]`, `(Хук)` и других.
- Подсчёт символов и увеличения размера UTF-8.
- Инспектор невидимых специальных символов.
- Копирование результата одной кнопкой.
- Преобразование выполняется локально в браузере.

## Использование

1. Откройте приложение.
2. Вставьте текст в левое поле.
3. Выберите метод преобразования.
4. Оставьте сохранение тегов включённым, если в тексте есть структурные обозначения.
5. Проверьте и скопируйте результат.

> [!IMPORTANT]
> Платформы обрабатывают Unicode по-разному. Сервис может удалить, заменить, отклонить, озвучить или показать специальные символы. Всегда проверяйте результат в нужном вам сервисе.

## Как это работает

- **Невидимые символы:** вставляются `U+200B`, `U+200C` и `U+200D`.
- **Мягкий перенос:** `U+00AD` вставляется через определённые позиции.
- **Омоглифы:** некоторые латинские буквы заменяются визуально похожими кириллическими.

Режимы невидимых символов и мягкого переноса поддерживают буквы любых алфавитов, включая кириллицу. Режим омоглифов заменяет только поддерживаемые латинские символы. Отдельные строки формата `[...]` или `(...)` могут оставаться без изменений.

## Конфиденциальность

Введённый текст обрабатывается локально и не отправляется на сервер приложения. Страница загружает Tailwind CSS и Google Fonts из публичных CDN, поэтому обычные сетевые запросы к этим провайдерам всё же выполняются.

## Ответственное использование

Обрабатывайте только материалы, на использование которых у вас есть права, и соблюдайте правила платформы, куда отправляете результат.
